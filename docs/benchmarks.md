## Method

- **Corpus:** Xiph.org derf CIF sequences (akiyo = low motion, foreman = medium, mobile = high), first 100 frames, 4:2:0. Audio is 30 s mono 48 kHz excerpts of the Sintel trailer audio and Elephants Dream's music (ED-CM stereo, downmixed).
- **Video metric:** every codec's output is decoded and scored by the *same* ffmpeg PSNR and SSIM filters against the source. Rate is the raw payload, with no container overhead on either side. Each codec is swept over its quality setting; a single point means little, the curve is the result.
- **Video references:** the *offline ceiling* is the best of x264 `veryslow`, x265 `veryslow` and SVT-AV1 preset 4 at default tuning. The *real-time references* are x264 `veryfast` with `zerolatency` and libvpx VP9 `realtime` at `cpu-used 8`, the settings low-latency encoders run with. Thrum is a low-latency codec, so the real-time group is the fair comparison; the offline ceiling shows the distance to the best encoders.
- **Same-toolset references:** `spec.txt` forbids CABAC and fractional interpolation, so the other references use tools the codecs may not. `x264-same-tools` is x264 `veryfast` + `zerolatency` with CAVLC, full-pixel motion, no RDO, one reference and no B-frames (Thrum's toolset). `x264-cavlc` is x264 `veryslow` with only CABAC removed; it still has quarter-pixel motion, so it is stronger than Vault's toolset. These are the fair yardsticks: a gap to them is implementation, a gap to the others is partly the spec.
- **Video equal-quality columns:** how many times *larger* the tpt stream is than the cheapest reference in that group at the same luma PSNR (log-linear interpolation). `>1` means tpt is worse; `n/a` means the PSNR is outside the reference's range.
- **Audio, lossless:** Aura is compared by size against FLAC (compression level 8), WavPack (level 3) and ALAC (muxed into m4a, so a few kB of container is included), and against an *estimate* of an ideal predictor (order-32 LPC per 4096-sample block, ideal Laplace entropy coder, side info ignored). The estimate is not a proven bound.
- **Audio, stereo:** the Elephants Dream stereo excerpt (not downmixed) through Aura's stereo lossless path against FLAC-8, WavPack and ALAC at the same settings as the mono table. Aura is measured at its CLI block size (8192 samples); the mono table is measured the same way.
- **Audio, lossy:** Cinder is swept over bit depth (4–12, via `--quality`) and per-band step (`--band-step`, half-octave grid from 1/1024 to about 45). Rate is the codec's payload, not the file size. The Cinder rows use the lowest rate that reaches each SNR over the whole grid, which is an oracle choice: a shipped encoder would need rate control to find the step. Cinder v5 range-codes its levels under one of 16 fixed geometric models chosen per packet (a 4-bit class), so it no longer pays a per-coefficient floor. The entropy proxy is the remaining headroom: it uses ideal per-band histograms fitted to each clip.
- **Audio, lossy references:** Opus (libopus via ffmpeg, mono 48 kHz, 12–128 kbps) and AAC-LC (ffmpeg's native encoder, mono 48 kHz, raw ADTS, 16–128 kbps). Both are perceptually tuned and SNR is a waveform metric, so they are expected to look worse here than they sound; read the SNR columns as a waveform-fidelity comparison, not a listening test.
- **SNR alignment:** every decoded signal is aligned to its source by the best integer lag within ±2048 samples before SNR is taken, so a codec's fixed delay does not count as error.
- **Audio, bound:** the Gaussian rate-distortion bound from reverse water-filling over 16 bands per 256-sample DCT block, each band's variance taken as its power in that block, plus 4 bits per band per block of side information (about 12 kbps). It is an estimate for that envelope model, not a proven bound on every source. Earlier runs used per-coefficient variances with no side information; those numbers were far too optimistic and are not comparable.
- **Speech:** ITU-T P.862 narrowband PESQ on two 20 s Open Speech Repository clips, both sides resampled to 8 kHz. Cinder and Opus run at 48 kHz on the original clips. Codec 2 (libcodec2, five modes) and Reed (a quality sweep) run at 8 kHz, their native rate. Each cell is the lowest rate that reaches that PESQ on each clip, averaged over the clips. PESQ is a speech metric, so it says nothing about music.
- **Cinder's wire step:** version 3 carries steps in 1/1024 units. Version 2 wrote whole numbers only, which made every step below 1.0 decode to near silence; the rows below post-date that fix.
- **Cinder's loudest peaks clip at fine steps.** At 12 bits the range is about ±2048 × step, so a step of 0.001 clips coefficients above about 2. The sweep includes those points; the SNR column shows the cost.
